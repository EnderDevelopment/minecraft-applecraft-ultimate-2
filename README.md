# AppleCraft Ultimate

AppleCraft Ultimate is a comprehensive Minecraft Bedrock Edition addon that introduces 35 unique types of apples, each with distinct textures, special effects, balanced crafting recipes, and unique utilities. Designed for Android, especially Samsung Galaxy Tab S7 FE, this addon prioritizes performance, stability, and compatibility with existing worlds. It features a new food system with progression, rarity, powers, visual effects, and special mechanics, ensuring a rich and engaging gameplay experience.

## Install

1. Download the AppleCraft Ultimate addon from the GitHub repository or the EnderDevelopment marketplace.
2. Open Minecraft Bedrock Edition.
3. Go to the "Add-ons" section in the settings menu.
4. Click on the "+" button to add a new addon.
5. Navigate to the downloaded addon file and select it.
6. Ensure the addon is enabled in the add-ons list.
7. Start a new world or load an existing one to use the AppleCraft Ultimate addon.

## Use

1. Craft the apples using the provided recipes.
2. Consume the apples to gain their respective effects.
3. Explore the unique utilities and special mechanics of each apple.
